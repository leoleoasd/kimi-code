Send the user an out-of-band OS/browser notification (NOT a chat message — it lands in the user's notification center and never enters this conversation).

Use when you need the user's attention OUTSIDE the chat surface: long work finished, you are blocked on something only they can resolve, or an important failure needs surfacing while they may be away. Prefer ordinary output for anything conversational; notifications are for interrupts.

`title` is one short headline line; `body` one or two sentences.
